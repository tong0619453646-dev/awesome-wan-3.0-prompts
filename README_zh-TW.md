**網頁上用：** 每則都有「在 APIKO 執行」連結，會在 [apiko.app](https://apiko.app/zh-tw/wan-3-0-prompts?utm_source=github&utm_medium=quickstart&utm_campaign=awesome-wan-3.0-prompts&utm_content=browser) 開啟這則範例；點「使用」，提示詞與參考素材就會填進 Wan 3.0 試用台。

**用 API：** 先建立 [APIKO API 金鑰](https://apiko.app/zh-tw/dashboard/apikeys?utm_source=github&utm_medium=quickstart&utm_campaign=awesome-wan-3.0-prompts&utm_content=api_key)，再建立任務並輪詢，直到影片生成完成。參考圖、影片與音訊寫在請求內容裡，見[常見問題](#faq)。

```bash
export APIKO_API_KEY="your_key_here"

TASK_ID=$(curl https://api.apiko.app/v1/videos \
  -H "Authorization: Bearer $APIKO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "wan3.0-text-to-video",
  "duration": 5,
  "resolution": "720p",
  "aspect_ratio": "16:9",
  "prompt": "A paper boat drifting across a calm lake at sunrise, slow cinematic camera move."
}' | python3 -c 'import json,sys; print(json.load(sys.stdin)["id"])')

while :; do
  TASK=$(curl -s https://api.apiko.app/v1/videos/$TASK_ID \
    -H "Authorization: Bearer $APIKO_API_KEY")
  printf '%s\n' "$TASK"
  printf '%s' "$TASK" | grep -qE '"status": *"(completed|failed)"|"error": *\{' && break
  sleep 5
done
```

介面: `POST https://api.apiko.app/v1/videos` (建立任務) · `GET https://api.apiko.app/v1/videos/{id}` (查詢狀態並讀取 `video_url`)

<a id="how-to-write"></a>
## ✍️ Wan 3.0 提示詞怎麼寫

四種寫法，改寫自官方手冊。

- **基礎公式** · `主體 + 場景 + 運動` — 誰或什麼、在哪裡、做什麼。第一次上手夠用，也替模型留了發揮空間。
- **進階公式** · `主體 + 場景 + 運動 + 美學控制 + 風格化 + 音效` — 補上光線、景別、視角與運鏡，點明畫面風格，再寫聲音。運動要說幅度與快慢（「緩慢地」「猛烈地」）以及造成的效果。
- **圖片或首幀** · `運動 + 運鏡` — 圖片已經決定主體、場景與風格，只寫什麼在動，以及鏡頭怎麼跟。
- **聲音** · `人聲 + 音效 + 配樂` — 寫出每句台詞或旁白並描述音色（低沉沙啞、可愛），再寫音效與背景音樂。

**範例裡看得到的寫法**

- **長影片按時間切段。** 30 秒的提示詞都拆成鏡頭或分段，各給一個時間範圍，例如「分段1[0-5秒]」「(0:00 - 0:03)」。
- **聲音直接寫進提示詞。** 音效放在角括號裡，<腳步踩在木地板上的兩聲輕響>；台詞放在大括號裡，{走吧}。
- **素材按編號稱呼。** 用「圖1」「影片1」「音訊1」（英文寫 Image1、Video1、Audio1），編號與傳入順序一致。
- **先寫改動，再鎖其餘。** 編輯類提示詞只說一處改動，結尾交代不變的部分：「女人的動作和畫面其餘部分保持不變」。
- **延長時留意 30 秒上限。** 輸入加輸出的總長不超過 30 秒，所以 15 秒的影片最多再延長 15 秒。

畫面：鏡頭快速推進到刀客斗笠下的特寫。
細節：斗笠邊緣露出一雙凌厲、決絕的眼睛，眼神如刀。水墨暈染的“汗珠”從額頭滑落。
動作：刀客右手緩緩握緊刀柄，指關節泛白。竹葉飄落的速度加快。

(0:08 - 0:13) 運鏡：快速環繞。

畫面：鏡頭以刀客為中心快速環繞。
劇情：兩名同樣是水墨剪影的刺客從竹林深處殺出，手持雙鉤和短刃。
細節：刺客的動作也是水墨筆觸構成的，如墨跡流動。鏡頭快速掠過刺客的身影，強調速度感。

(0:13 - 0:18) 運鏡：手持感，高速捕捉。

打鬥：刀客猛然拔刀，刀光是一道純白色的水墨裂痕。刺客雙鉤攻來。
細節：
一擊：刀客回身一斬，刀刃與刺客雙鉤碰撞，迸發出無數黑白相間、帶有書法感的火花和墨點。
二擊：刀客虛晃一槍，利用竹竿彈射，從高處劈下。刺客翻滾躲避。竹竿被打斷，化作飛散的墨痕。
三擊：刀客刀尖直指另一刺客咽喉，刺客以短刃格擋，鏡頭捕捉刀刃與短刃摩擦時細微的墨跡崩裂細節。



**(0:18 - 0:20) 運鏡：慢鏡頭至定格。**

* **畫面：** 刀客的刀停在刺客頸側，刺客凝固。
* **細節：** 刀客的斗笠在打鬥中略微傾斜。竹林歸於平靜，更多竹葉飛舞。
* **氛圍：** 鏡頭慢慢拉遠，回到中景，定格在刀客收刀、刺客倒地的畫面。
* **文字（可選）：** 畫面下方顯現水墨風文字：“江湖，不過一筆勾銷。”

**風格說明：** 整個過程保持 `image_0.png` 的高度黑白、水墨畫風格，動作必須有毛筆觸感，速度要快，細節要足（墨滴、火花、墨痕裂口）。

## ❓ 常見問題

<details>
<summary><b>這些 Wan 3.0 提示詞可以免費使用嗎？</b></summary>

可以，提示詞可以免費複製、修改與執行。範例影片屬於阿里，發布在它的公開手冊裡：僅作參考，不要當成自己的素材，要轉用請先閱讀阿里的條款。你自己生成的影片，請確認上傳的素材你有權使用。

</details>

<details>
<summary><b>提示詞一定要寫中文嗎？</b></summary>

不必。Wan 3.0 支援中英文提示詞，最長 20,000 字元。官方原文是中文，英文、繁體中文與韓文版本是翻譯，「複製」會給出目前網站語言的版本。

</details>

<details>
<summary><b>怎麼透過 API 傳參考圖、影片與音訊？</b></summary>

在 Wan 3.0 參考生影片裡，用 HTTPS 連結填 reference_image_urls（最多 10 個）、reference_videos（最多 5 個，每個 1-15 秒，合計 15 秒）與 reference_audios（最多 5 個）。圖生影片用 first_image_url 與 last_image_url。參數與範例見 Wan 3.0 文件。

</details>

<details>
<summary><b>Wan 3.0 生成一段影片要多少錢？</b></summary>

按輸出秒數計費，參考影片的秒數也計入。各家附日期的價格見 Wan 3.0 API 價格比較。

</details>
